# ORBIT

A one-tap rhythm game. A ship rides a ring; tap the instant it meets the target. Targets land on the beat, the music builds as you rank up, and every hit is worth one point.

**Play:** https://mezg0.github.io/orbit/

Controls: tap, click, or press Space. `M` mutes, `P` pauses.

Single static `index.html`, no build step, no dependencies. Sound is synthesized live with the Web Audio API.
